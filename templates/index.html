Required File Format

Your CSV or Excel file must have Row 1 as a header row with these column names, followed by your sprint data rows. Column order must match exactly.

Column Header Name Example Values Notes
ASprintSprint 3, Q1-W2Groups tickets; latest sprint is auto-detected
BTypeTask, Bug, Story, EpicMaps to Jira issue type
CTitleAdd OAuth2 login flowBecomes the Jira summary
DClient ImpactHigh, Medium, Low, CriticalMaps to Jira priority
EEffort3, 5, 8, 13Story points
FOwnerJane SmithTicket reporter / owner
GStatusTo Do, In Progress, DoneCurrent status
HAssigneeBob JohnsonJira assignee
